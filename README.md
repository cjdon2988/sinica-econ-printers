# 中研院經濟所印表機設定(Mac)

用 Claude Code 一次設定經濟所的五台印表機:電腦室四台、C 棟 2 樓一台。

## 你需要

- 一台 Mac,有安裝 Claude Code。
- 人在中研院網路上(有線、院內 Wi-Fi 或 VPN)。
- 這台 Mac 的管理員帳號(新增印表機要輸入一次密碼)。
- 這是 private repo。作者邀請你之後,先到 GitHub 接受邀請,並在 Mac 上用 `gh auth login` 登入,Claude 才讀得到。

## 怎麼用

1. 在 Mac 上開 Claude Code。
2. 把這個 repo 的連結貼進對話,說:「幫我照這個 repo 設定印表機」。
3. Claude 會一次問你幾個問題(你在哪辦公、要裝哪幾台、要不要改名、預設雙面、你自己的列印習慣),你用選項回答就好。
4. 問完它會給你一支腳本。你自己開「終端機」執行一次、輸入一次密碼,就設定完畢。

## 給 Claude Code 的指示

如果你是 Claude Code,而使用者把這個 repo 的連結貼進對話:

1. 把 repo clone 到一個暫存位置(不要放進使用者的工作資料夾)。
2. **讀 `SKILL.md` 並照流程執行。** 鐵則在 SKILL.md 最前面:只支援 Mac、絕不輸入或詢問密碼、只改印表機設定、先唯讀後修改。
3. 用互動選項一次問完,不要反覆追問。
4. 印表機資料在 `printers.md`,作者習慣在 `reference/author-habits.md`(只是參考,要問使用者是否認同)。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `SKILL.md` | 完整設定流程與問題清單 |
| `printers.md` | 五台印表機的位置、位址、型號、色彩、雙面、建議名稱 |
| `scripts/setup_template.sh` | 一次性設定腳本範本(執行完自刪) |
| `reference/author-habits.md` | 作者的列印習慣,僅供參考 |

## 範圍與限制

- 只支援 macOS(使用 CUPS)。
- 這個 repo 只會新增、改名印表機與設定預設值,不碰網路或其他系統設定,也不會刪除你既有的印表機,除非你明確要求。
- 印表機位址是院內私有網路,不在院內連不到。
