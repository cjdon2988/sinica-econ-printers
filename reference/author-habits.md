# 作者的列印習慣(僅供參考)

這是 repo 作者自己的習慣,**不是預設值,也不是規定**。設定流程裡 Claude 會把這幾條拿給你看,問你是否認同、有沒有要補充或修改。你可以全部採用、部分採用,或完全不採用。

## 作者習慣

1. **多份文件合併雙面列印**:單數頁的那份文件後面補一張空白頁,讓每份文件都從新的一張紙正面開始,不和上一份背靠背。這條不分印表機。
2. **彩色整疊印(只限中研院的彩色印表機)**:一疊文件裡只要有彩色頁,整疊直接送彩色機,不拆開分黑白和彩色。原因是雷射彩色機印黑白內容不會多耗碳粉。家裡或其他地方的印表機不套用。
3. **優先順序**:彩色優先用大白,黑白優先用大黑二。
4. **預設雙面**:所有印表機預設雙面,長邊翻頁。
5. **隨印表機調整**:習慣會隨使用的印表機不同而改變,除非有特別指定的偏好。

## 這份參考想傳達的

很多人習慣不一樣:有人固定用同一台,有人依位置選最近的,有人儘量印黑白省成本。設定的重點是把**你的**習慣問清楚並落地,不是複製作者的。
